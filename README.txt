DESI WULANSARI PORTFOLIO
========================

1. Buka index.html di browser untuk preview.
2. Masukkan foto profile ke:
   assets/images/profile.jpg
3. Masukkan foto sekolah ke:
   assets/education/school.jpg
4. Masukkan foto experience ke:
   assets/experience/bpjs.jpg
5. Masukkan gambar sertifikat ke folder:
   assets/certificates/
6. Masukkan gambar project ke:
   assets/projects/
7. Letakkan CV dengan nama:
   Desi-Wulansari-CV.pdf

PENTING:
- Ganti email, GitHub, LinkedIn, Instagram, TikTok, dan YouTube di index.html.
- Ganti placeholder gambar sesuai file yang kamu punya.
- Website ini static HTML/CSS/JS dan siap untuk GitHub Pages / Cloudflare Pages.
