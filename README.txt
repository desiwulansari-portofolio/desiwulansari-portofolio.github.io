# DESI WULANSARI — Interactive Portfolio

## Quick start
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Put your real profile photo at:
   `assets/images/profile/profile.jpg`

The image is intentionally rendered with `width: 100%` and `height: auto`, so its original aspect ratio is preserved.

## Replace before publishing
- `hello@example.com` in `index.html`
- LinkedIn / GitHub / WhatsApp `href="#"` links
- Project descriptions and images
- University name
- Profile photo

## Visual direction
Creative editorial / experimental personal portfolio:
- kinetic typography
- graphic shapes
- marquee
- orbiting photo frame
- scroll reveal
- magnetic buttons
- custom cursor
- interactive project tilt
- animated skill constellation
- responsive mobile layout

No framework required.
