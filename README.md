# Desi Wulansari — Portfolio

Portfolio static HTML/CSS/JavaScript berdasarkan brief yang diberikan.

## Struktur
- `index.html` — halaman utama
- `style.css` — design system, responsive layout, animation
- `script.js` — modal, project filter, mobile menu, scroll reveal
- `assets/` — tempat foto sekolah, sertifikat, project screenshot, pengalaman
- `Desi-Wulansari-CV.pdf` — letakkan CV asli di root

## Menjalankan
Tidak membutuhkan npm/build tool. Buka `index.html` langsung di browser.

## Deploy
Bisa di-upload ke GitHub Pages atau Cloudflare Pages sebagai static site.
